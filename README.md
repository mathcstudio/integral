# ∫ 정적분 탐구실 — 설치·배포 안내

미적분을 처음 배우는 학생이 직사각형을 쪼개 보며 정적분의 뜻을 탐구하는 웹 앱입니다.
(8단계 탐구 + 보너스 게임 '정적분 골프')

## 구조

```
학생 브라우저 ──(GitHub Pages)── index.html        ← API 키 없음
        │
        └─ AI 요청 ──▶ Google Apps Script (Code.gs) ──▶ Gemini API
                       · 교사 PIN(해시로만 저장)
                       · Gemini API 키
                       · 사용량 제한
```

- API 키와 교사 PIN은 **구글 앱스크립트의 스크립트 속성**에만 저장됩니다. 학생 화면·코드·GitHub 어디에도 남지 않습니다.
- AI 서버가 없거나 꺼져 있어도 앱은 **규칙 기반 피드백**으로 정상 동작합니다.

---

## 1단계. 구글 앱스크립트 서버 만들기 (약 5분)

1. <https://script.google.com> 에 접속 → **새 프로젝트**
2. 프로젝트 이름을 `정적분 탐구실 AI 서버` 등으로 바꿉니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣고 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(⚙) → **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인(본인 구글 계정) → 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 권한 승인 화면에 "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르세요. 본인이 만든 스크립트라 안전합니다.

## 2단계. 앱에 서버 주소 넣기

[`index.html`](index.html)에서 아래 줄을 찾아 1단계에서 복사한 주소를 넣고 저장합니다.

```js
const GAS_URL = 'https://script.google.com/macros/s/여기에_복사한_주소/exec';
```

## 3단계. GitHub Pages로 배포하기

1. <https://github.com/new> 에서 새 저장소를 만듭니다. (예: `definite-integral-lab`, **Public**)
2. 이 폴더의 파일(`index.html`, `README.md`, `apps-script/`)을 저장소에 올립니다.
   - 웹에서: 저장소 화면의 **Add file → Upload files**로 끌어다 놓기
   - 또는 명령어(이 폴더에서):
     ```bash
     git remote add origin https://github.com/<내아이디>/definite-integral-lab.git
     git push -u origin main
     ```
3. 저장소의 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → **Save**
4. 1~2분 뒤 `https://<내아이디>.github.io/definite-integral-lab/` 주소로 접속됩니다. 이 주소를 학생에게 안내하세요.

## 4단계. 첫 관리자 설정 (꼭 하세요!)

1. 배포된 주소에 접속 → 오른쪽 위 **⚙ 관리자** → PIN `1234` 입력
2. **Gemini API 키** 입력, **새 관리자 PIN**(4자리 이상) 입력 → **저장**
3. **연결 테스트**로 "연결 성공"이 나오는지 확인합니다.

> 처음 PIN(1234)은 누구나 알 수 있으니, 배포하자마자 바꾸세요.
> 앱 대신 앱스크립트 편집기에서 `setupOnce()` 함수에 키·PIN을 넣고 한 번 실행해도 됩니다. (실행 후 코드에서 값을 지우세요.)

## 관리자 화면에서 할 수 있는 일

| 기능 | 설명 |
|---|---|
| API 키 저장·삭제 | 서버에만 저장, 화면에는 끝 4자리만 표시 |
| 모델 선택 | 기본 목록 또는 '목록 불러오기'로 사용 가능한 모델 확인 |
| AI 켜기/끄기 | 끄면 학생은 규칙 기반 피드백만 받음 (시험 기간 등) |
| 사용량 제한 | 1분당·하루 요청 수 (반 전체 합계, 기본 40회/분 · 1500회/일) |
| PIN 변경 | PIN은 해시로만 저장, 5번 틀리면 10분 잠금 |
| 진행 상황 초기화 | 그 기기의 학생 진행 기록만 지움 |

## 보안 메모

- 웹 앱 주소는 공개되지만, 서버는 **이 앱의 피드백·질문 기능만** 처리하고 입력 길이·사용 횟수를 제한합니다.
- 키를 바꿔야 할 때는 관리자 화면에서 새 키를 저장하면 즉시 반영됩니다.
- `Code.gs`를 수정했다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. (주소는 그대로 유지)

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 배지가 계속 "AI 피드백 꺼짐" | `GAS_URL` 주소, 배포 액세스가 '모든 사용자'인지, 관리자 화면에서 AI 켜기·키 저장 여부 |
| 관리자 로그인 시 오류 | 앱스크립트 배포를 '새 버전'으로 다시 했는지 |
| "오늘 사용할 수 있는 AI 횟수를 모두 썼어요" | 관리자 화면에서 하루 제한을 늘리기 |
| iPad에서 파일로 열면 안 됨 | GitHub Pages 주소(https://…github.io/…)로 접속하세요 |
